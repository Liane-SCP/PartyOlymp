# Sicherheit

Sicherheitslücken nicht mit Zugangsdaten oder aktiven Raumtokens in öffentlichen Issues melden. Wenn GitHub Private Vulnerability Reporting aktiviert ist, diesen Kanal nutzen; andernfalls einen privaten Kontakt mit dem Repository-Eigentümer vereinbaren.

Keine `.env`-Dateien, privaten Schlüssel, Datenbankkopien, Cloudflare-Tokens oder GitHub-Tokens committen. Bei versehentlicher Veröffentlichung betroffene Zugangsdaten zuerst widerrufen und ersetzen; das Löschen der Datei allein genügt nicht.

Die Exportprüfung sucht nach einigen bekannten Geheimnisformaten. Sie ist keine vollständige Sicherheitsprüfung. Vor öffentlicher Freigabe zusätzlich Quelltext, Historie und Medienrechte prüfen.
